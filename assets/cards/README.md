## كيفاش نزيد / نبدّل كارطة

1. حط الملفات الجدد ف `cart/` (بأي اسم — مثلا `10 dheb-vector-xxxx.svg`)
2. شغّل:

```bash
node tools/import-cards.js --dry     # كيوريك أش غادي يتدار، بلا ما ينسخ
node tools/import-cards.js           # كينسخ ل assets/cards/<suit>-<rank>.<ext>
```

السكريبت:
- كيفهم `dheb` = `dhab` و `jben` = `kass`
- كيتجاهل الدوبلونات (مثلا `... (1).svg`)
- كيعطيك ليستة ديال **اللي ناقص**
- كيحذّر يلا كان الـ `viewBox` ماشي بنسبة الكارطة
